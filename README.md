# SQL Data Analytics Project

A hands-on SQL data analytics project focused on Exploratory Data Analysis
(EDA) and Advanced Analytics using SQL Server.

This project was completed as a learning project based on the following
courses by Baraa :

- [SQL Exploratory Data Analysis (EDA) Project](https://youtu.be/6cJ5Ji8zSDg)
- [SQL Data Analyst Portfolio Project](https://youtu.be/2jGhQpbzHes)

The project covers the process of exploring a relational database,
understanding its dimensions and measures, analyzing business metrics,
identifying trends and patterns, and building analytical reports using SQL.

---

## Project Overview

The project is divided into two main stages:

### 1. Exploratory Data Analysis (EDA)

The first stage focuses on understanding the structure and content of
the database before performing deeper analysis.

Topics covered:

- Database Exploration
- Dimensions Exploration
- Date Exploration
- Measures Exploration
- Magnitude Analysis
- Ranking Analysis

### 2. Advanced SQL Analytics

The second stage focuses on using SQL to perform more advanced
analytical tasks and answer business-oriented questions.

Topics covered:

- Change-Over-Time Analysis
- Cumulative Analysis
- Performance Analysis
- Part-to-Whole Analysis
- Data Segmentation
- Customer Report
- Product Report
